## Ошибка открытия внутренних страниц в офлайн-архиве

**Причина:** в RU v3.1 ссылки заканчивались на каталог (`../ru/about/`), что обычно работает на веб-сервере, но не гарантирует открытие `index.html` при просмотре из `file://`.

**Решение:** отдельная офлайн-сборка `preview_offline/` из существующей `dist/` с переписыванием внутренних адресов на явные HTML-файлы (`../ru/about/index.html`). Для публикации на домене остаётся каталог `dist/` с привычными адресами страниц.

- [x] Переписаны 1598 ссылок на каталоги в 74 HTML-файлах.
- [x] Проверено 1818 локальных ссылок/ресурсов, все ведут на существующие файлы.
- [x] 13 автоматических тестов прошли.
