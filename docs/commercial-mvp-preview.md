# Закрытое коммерческое превью SalutRussie

Сборка основана на PR № 1 (bf4fa4a) и отдельном исправлении подменю и офлайн-генератора. PR воспроизведён на Mac. 15 тестов исходного PR и 16 тестов ветки MVP прошли.

На странице «Все услуги» собраны прежние направления с прямыми ссылками на программы и услуги. Русские тарифы показывают порядок обращения и ждут согласования позиций и сумм. Уведомление о персональных данных описывает фактическое поведение предварительной сборки. Утверждение политики рабочего сайта остаётся отдельным этапом.

`python3 -B build.py` собирает dist. `python3 -B make_offline_preview.py` делает офлайн-копию. Сборка использует исходную зависимость BeautifulSoup. `python3 -B -m unittest discover -s tests -v` запускает проверки. В этой ветке флаг PUBLIC_RELEASE=1 останавливает сборку до записи.

Два редакционных черновика из da2d216 добавляются только в отдельную временную копию для владельца. Исходные Markdown-файлы и матрицы проверки находятся в editorial/chatgpt-guides. В dist и preview_offline черновиков нет. Расчёт на 2027 год ожидает проверки нормы и региональных параметров.

Для возврата к исходной версии откройте `baseline-pre-ai-ru-v3.2` в отдельном worktree. Для просмотра прежних изменений используйте исходную ветку PR № 1. Обе точки сохранены.
