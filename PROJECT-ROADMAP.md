## Правила
Русская версия — единственный содержательный оригинал. Сначала утверждение русской страницы, потом полные EN/FR переводы без сокращений. Дизайн V3, согласованный на странице Указа 702, сохраняется. ## II. Переводы (приостановлены до утверждения русских оригиналов)
На V3.4: по 56 страниц RU/EN/FR. Статус полной содержательной синхронизации по предыдущему аудиту — EN 6, FR 8; требуется 50 EN + 48 FR = 98 проверок/переводов, из которых 28 — экспертные статьи. Эти числа не равнозначны независимой вычитке носителем языка.
Уже синхронизированы EN+FR: главная, migration/, migration/decree-702/, about/, consultations/, privacy/. Дополнительно FR: for-business/employers/, for-business/recruitment-partners/. После любой русской правки соответствующие переводы снова подлежат сверке.
Очередь:
1. Коммерческие услуги: миграция (14 языковых страниц), недвижимость (8), бизнес (8), инвестиции (8), правовая помощь (6), адаптация (8), общий каталог (2).
2. B2B (6 оставшихся языковых страниц).
3. 14 экспертных статей × 2 = 28 полных переводов; каталог статей (2).
4. Контакты, оферта, оплата, стоимость (8).
5. Сквозная сверка всех 56 комплектов: смысл, заголовки, все абзацы, таблицы, исключения, примеры, изображения, ссылки, метаданные, естественность юридической терминологии и дизайн. Повторная вычитка после правок RU.
## Порядок работы
Открыть одну русскую страницу — владелец перечисляет замечания — внести только согласованные правки — проверить — сохранить коммит — отметить утверждение в карте — перейти к следующей. Переводы начинать после утверждения соответствующего текста; до завершения русской проверки не запускать массовую переработку EN/FR.
