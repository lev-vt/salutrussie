# Визуальное ТЗ для Codex — РВП по Указу № 702

Статус: редакционное ТЗ, не команда к немедленному деплою. Сохранить визуальную систему Claude (тёмно-синий / бордовый / золото / пергамент, Fraunces и Inter); не вводить новый дизайн.

## Визуализация 1: «Не путайте четыре события»

Цепочка с четырьмя узлами: **выдана виза (если применимо)** → **въезд и требования к пребыванию** → **заявление и документы ПРИНЯТЫ МВД** → **решение / фактическая выдача РВП**. Под узлом подачи выделить тезис: «Запись на приём не равна принятию заявления». Под узлом визы: «Однократная виза не даёт повторного въезда». Без имитации печатей, официальных гербов и фальшивых бланков.

## Визуализация 2: календарь справки о несудимости

Горизонтальная шкала: дата выдачи → апостиль/легализация → перевод → планируемая дата подачи. Для демонстрации можно использовать **относительную** шкалу «до подачи», но не генерировать ложные сроки оформления услуг. Подпись: «По официальному разъяснению консульства, при подаче по Указу № 702 обращайте внимание на 3 месяца с даты выдачи справки; проверяйте индивидуальные условия». Никаких персональных данных.

## Визуализация 3: таблица «виза vs РВП»

Две визуально равнозначные колонки с различиями по назначению, сроку действия (для спецвизы только), возможному повторному въезду, обязанностям после выдачи. У РВП не показывать придуманные гарантии и услуги.

## UX

- Доступность: контраст AA, семантические заголовки, alt-тексты описывают смысл, не декоративный узор; мобильная прокрутка таблиц.
- В интерактивные «проверки права на РВП» не включать автоматическое заключение о праве на выдачу. Если в будущем делать pre-screening, только через отдельное проверенное юридическое ТЗ.
- Кнопки не открывать форму с ненужными полями; CTA вести на существующие коммерческие страницы.
- Ссылки на официальные документы видимы рядом с тезисами.
- Исключить изображения реальных мигрантов, вымышленных клиентских историй и государственные логотипы без отдельной проверки прав.
