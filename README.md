# SalutRussie

Статический сайт юридической практики для иностранцев в России. Это развитие существующего проекта: исходные страницы и дизайн сохранены в `src/original/`, генератор — `build.py`. Текущая рабочая ветка для просмотра владельцем — `ai/site-ready-20261121`. Публикация не выполнялась.

## Просмотр и сборка

Нужен Python 3.11+; внешние пакеты не требуются.

```bash
python3 -B build.py
python3 -B make_offline_preview.py
python3 -B -m unittest discover -s tests -v
```

- `dist/` — веб-сборка для локального HTTP-сервера. Команда: `python3 -m http.server 4173 --directory dist`; адрес: `http://localhost:4173/`.
- `preview_offline/index.html` — вариант для открытия двойным щелчком на Mac без сервера. Он содержит ссылки на `index.html` внутри каждой папки.
- По умолчанию обе сборки закрыты от индексации (`noindex`, `robots.txt: Disallow: /`).

Для **локальной проверки** SEO-сборки без изменения `dist/`:

```bash
BUILD_VARIANT=release-check SITE_ORIGIN=https://example.invalid PUBLIC_RELEASE=1 python3 -B build.py
python3 -B verify_release.py
```

Результат окажется в игнорируемой Git папке `build/release-check/`. Это тест генератора; никакой отправки на сервер нет. Проверка подтверждает маршруты, внутренние ссылки, canonical, hreflang, sitemap, метаданные, структурированные данные и базовую доступность HTML. Перед реальным запуском владелец должен подтвердить точный домен, оператора персональных данных и политику обработки, а также провести окончательную юридическую приёмку экспертных материалов. Тарифы на сайте описаны без неподтверждённых сумм. Страницы `/ru/privacy/` и `/fr/privacy/` фактически описывают работу каналов связи; они имеют `noindex` и не выдаются за утверждённую политику обработки данных.

## Структура

- `build.py` — маршруты, общий каркас, стили и генерация HTML/SEO.
- `site_html.py` — небольшой разбор HTML на стандартной библиотеке для исходных страниц и тестов.
- `articles_content.py` — четыре переработанные статьи RU/FR.
- `article_addenda.py` — дополнительные практические разделы статей RU/FR перед FAQ.
- `service_content.py`, `subpage_content.py` — содержание основных направлений и детальных страниц RU/FR.
- `b2b_content.py` — раздел `/ru/for-business/`, `/en/for-business/`, `/fr/for-business/` с направлениями для работодателей и агентств.
- `verify_release.py` — проверка публичного варианта без размещения в сети.
- `package_release.py` — проверка и архивирование публичной сборки для подтверждённого домена; автономный комплект владельца.
- `docs/PUBLISHING.md` — пошаговая инструкция по самостоятельной публикации и проверке после загрузки.
- `src/original/` — архивные страницы исходной концепции; не являются автоматически утверждённым юридическим содержанием.
- `src/fonts/` — локальные Fraunces и Inter, лицензии SIL OFL и контрольные суммы; сборка копирует их в `assets/`.
- `dist/` и `preview_offline/` — генерируемые, но хранящиеся в Git результаты.
- `tests/` — проверка маршрутов, внутренних ссылок, контента и offline-версии.
- `docs/research-2026-11-21.md` — источники и пределы правовой проверки; `docs/README-history.md` — предыдущая документация проекта.
- `docs/privacy-policy-draft.md` — RU/FR проект политики с полями для фактов оператора и хостинга; не включён в сайт.
- `PROGRESS.md` — план, выполненные шаги и следующие проверки.
- `REPORT.md` — результаты и вопросы для приёмки владельцем.

## Контакты и данные

На сайте нет формы, которая отправляет данные на сервер. Контактные действия открывают WhatsApp, Telegram или почтовое приложение; пользователь отправляет сообщение сам. Не передавайте чувствительные документы в первом обращении. Аналитика и платёжные формы не подключены.
