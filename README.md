# SalutRussie — первый рабочий прототип платформы (v2)

Дата сборки: 20.10.2026. Исходный проект — ZIP, предоставленный пользователем из Claude. Его дизайн **не заменён**: основные стили, типографика, цветовая палитра, эмблема и существующие страницы сохранены. Коммерческая платформа расширена новыми страницами и компонентами.

## Что смотреть

1. Распакуйте ZIP и откройте **`dist/index.html`** двойным щелчком; он ведёт на русскую версию. Для французской версии — `dist/fr/index.html`.
2. На главной посмотрите блоки **«Чем мы можем помочь»**, **«Указ №702»**, **«Как мы работаем»** и **«Полезная информация»**.
3. Нажмите **«Консультация»** в шапке и откройте `Полезная информация`. Поиск работает по заголовкам и аннотациям: попробуйте `бизнес` или `аренда`. Есть фильтры по темам и форматам.
4. Проверьте мобильное меню и французскую версию.

Лучше открывать сайт через локальный веб-сервер, чтобы проверить поведение как у опубликованного проекта:

```bash
cd SalutRussie_v2
python3 -m http.server 4173 --directory dist
```

Затем откройте http://localhost:4173/ — интернет не требуется, кроме загрузки веб-шрифтов Google Fonts (если нет интернета, сработают системные шрифты).

## Файлы

- `original-Claude-archive.zip` — первоначальный архив в исходном виде; резервная копия, не редактировать.
- `src/original/` — исходные HTML-страницы Claude, на основе которых формируется сборка.
- `build.py` — генератор статического сайта, использует `beautifulsoup4` (`python3 -m pip install beautifulsoup4`).
- `dist/` — готовые для просмотра HTML, CSS, JS, изображения. Для развёртывания важны именно файлы `dist/`.
- `dist/assets/claude-ru.css` / `claude-fr.css` — оригинальные стили Claude, без изменений.
- `dist/assets/platform.css` — только новые компоненты.
- `dist/assets/platform.js` — меню, интерактивность, поиск, подготовленные события аналитики.
- `tests/` — автоматические проверки.

## Безопасность и публикация

**ЭТО РЕДАКЦИОННЫЙ ПРОТОТИП, НЕ ГОТОВ К ПУБЛИКАЦИИ.** По умолчанию все страницы выставлены `noindex`, а `robots.txt` запрещает обход. Это намеренно: юридические тексты и стоимость услуг требуется утвердить, персональные данные — оформить корректно, а сайт — проверить визуально в браузере.

До публичного запуска нужно обязательно:

- Подтвердить домен, контакты, юридическое лицо, команду, цены и условия программы 702; провести актуальную юридическую проверку.
- Заменить редакционные примеры четырёх статей реальными проверенными материалами (сейчас они помечены черновиками и не индексируются).
- Согласовать политику обработки персональных данных и правомерность интеграции мессенджеров, аналитики/платежей.
- Проверить фотографии, отзывы, права на их публикацию.
- Провести браузерную проверку desktop/mobile, Lighthouse, навигации и форм; автоматическая проверка ниже **не заменяет** визуальную.
- Развернуть на домене и проверить HTTPS, редиректы, аналитические цели, Search Console/Вебмастер/Bing.

Для контролируемой публичной сборки после проверки:

```bash
SITE_ORIGIN=https://ВАШ-РЕАЛЬНЫЙ-ДОМЕН PUBLIC_RELEASE=1 python3 build.py
```

В этом режиме появятся canonical, hreflang, sitemap.xml и структурированные данные. **Непроверенные/неполные страницы по-прежнему останутся `noindex`; их нужно отдельно доработать и утвердить**. Для новых самостоятельных статей надо поставить реальные даты, источники и одобрение юриста. Не публикуйте поисковое содержимое только ради заполнения разделов.

## Важные изменения по сравнению с Claude

- Ссылки на `claude.ai/artifact/...` заменены на реальные локальные страницы внутри проекта.
- Базовые стили Claude вынесены в отдельные CSS — это не визуальная переработка.
- Главная ориентирована на **широкий спектр услуг иностранцам**, а не только миграционные вопросы.
- Добавлены рабочее меню услуг, выбор консультации, поиск/фильтры каталога публикаций.
- Русская и французская ветки доступны по `/ru/` и `/fr/`.
- Существующие страницы тарифов, Указа № 702, команды и контактов перенесены с исходным содержимым (некоторые требуют фактологического и юридического согласования).
- Структурированные данные, sitemap и hreflang генерируются при запуске публичной сборки с реальным доменом.
