# Deutsche Sprachversion / Немецкая локализация

Основа: RU, визуальные решения EN/FR. Язык `de`, адрес `/de/`, обращение Sie. Не утверждать наличие немецкой адвокатской квалификации: Jurist / rechtliche Unterstützung, не Rechtsanwalt без подтверждения. Не обещать консультацию на немецком до подтверждения языка общения.

## Терминология

- Указ 702: Erlass 702 des Präsidenten der Russischen Föderation (при первом упоминании); далее Erlass 702.
- РВП: Genehmigung zum vorübergehenden Aufenthalt (RVP).
- ВНЖ: unbefristeter Aufenthaltstitel (VNZh), если речь об общем бессрочном ВНЖ; исключения и срочные ВНЖ пояснять по русскому источнику.
- Гражданство: russische Staatsangehörigkeit.
- Миграционный учёт: migrationsrechtliche Registrierung (не Anmeldung по немецкому праву).
- МВД: Innenministerium der Russischen Föderation (MWD).
- Компания: Innovative Legal Solutions LLC; регистрационные номера OGRN и INN сохраняются.
- Не приравнивать российские статусы к немецким правовым институтам.

## Порядок работ

1. Общие JS-компоненты, сборщик SEO и валидатор: поддержка DE без активации.
2. Главная и основные коммерческие страницы; затем миграция, остальные услуги, B2B, статьи, юридические документы.
3. Проверка содержания, терминологии, внутренних ссылок и доступности всех 54 маршрутов.
4. Активация DE в корневом выборе языка, переключателях всех страниц, manifest и структурированных данных; проверка 217 страниц, 205 URL в sitemap и адаптивности.
5. Объединение с актуальной gh-pages после проверки; ZIP-релиз для REG.RU отдельно.

Не выпускать страницы-заглушки, не изменять существующие адреса, не публиковать промежуточный перевод.
